# Privacy

Prajnavex is local-first. The public repository should contain the framework, scripts, templates, and sanitized example notes. Raw captured materials are private by default.

## Keep Local

- Original PDFs, screenshots, and clipped assets unless explicitly cleared for sharing.
- SSH keys, tokens, cookies, browser profiles, and local service logs.
- Personal vault state, Obsidian workspace state, and temporary OCR output.
- Notes containing private names, account data, investment positions, or unpublished analysis.

## Safe to Share

- Project documentation.
- Empty or sanitized templates.
- Scripts that do not contain credentials.
- Redacted sample notes where source rights and privacy are acceptable.

Before pushing, run validation and inspect `git status` for raw source files or local secrets.
