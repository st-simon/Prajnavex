# Project Goal

Prajnavex turns messy source material into structured, reviewable, and
traceable knowledge.

## First Reliable Workflow

```text
document -> extracted evidence -> Source draft -> Card candidates
         -> duplicate warnings -> human review -> stable knowledge
```

One successful output is a Source draft plus zero or more Card drafts that:

- preserve the source identity and evidence;
- pass structural validation before promotion;
- keep one reusable idea per Card;
- warn about likely overlap with existing Cards;
- require an explicit human approval action.

## Top Constraint

Knowledge quality and traceability take priority over unattended automation.
Inputs may stay local, and no draft is promoted automatically.

## Deferred

- Automatic semantic merging.
- Autonomous Skill promotion.
- Cloud-only model dependency.
- Vector database infrastructure.
