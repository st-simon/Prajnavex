# Prajnavex v0.2 Roadmap

Status: in progress

Theme: schema integrity, staleness audit, and portable execution.

## Background

v0.1 proved the local-first pipeline:

```text
inbox -> source -> card -> skill -> bundle -> tool/workflow
```

v0.2 turns that pipeline into something safer to grow over time. The main upgrade is not more capture volume; it is better trust, traceability, and review discipline.

## Goals

- Validate frontmatter beyond required fields.
- Resolve links between sources, cards, skills, and bundles.
- Surface stale or under-reviewed knowledge before it silently decays.
- Generate bidirectional index data for future UI views.
- Remove demo-host path assumptions from shared documentation.
- Define the minimum real path from bundle to executable workflow draft.

## Non-Goals

- Multi-user sync and locking.
- Cloud deployment.
- Full desktop application packaging.
- Fully automatic semantic card merging.

## Workstreams

1. Deep validation: `scripts/knowledge_index.py --check` validates enums, dates, directories, duplicate IDs, and link targets.
2. Staleness audit: `scripts/knowledge_audit.py` reports missing review fields, stale notes, orphan cards, and validation warnings.
3. Bidirectional index: `--write-index` emits records plus backlinks.
4. Portability and privacy: document what stays local and replace shared absolute paths with placeholders.
5. Bundle execution seed: bundles carry input/output contract fields so they can later become workflow drafts.
6. Tests: add focused unit tests for parser, validation, backlinks, and audit rules.

## Bundle Execution Seed

Use this command to inspect bundle readiness:

```powershell
python scripts\bundle_tool_draft.py --list
```

When a bundle exists, render a workflow draft:

```powershell
python scripts\bundle_tool_draft.py --bundle-id bundle-YYYYMMDD-slug
```

## Acceptance

- `python scripts\knowledge_index.py --check` exits with no errors.
- `python scripts\knowledge_index.py --write-index` writes records and backlinks.
- `python scripts\knowledge_audit.py` exits successfully while surfacing warnings.
- `python -m unittest` passes.
- README, schema, templates, and task docs describe the v0.2 operating model.
