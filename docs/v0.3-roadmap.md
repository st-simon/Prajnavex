# Prajnavex v0.3 Roadmap

Status: verified

Release status: verified-uncommitted

Theme: guided semantic drafting with human approval.

## Goals

- One formal entry point for PDF, Markdown, and text ingestion.
- Local semantic Source and Card drafting through model roles.
- Evidence traceability for each Card candidate.
- Advisory semantic duplicate detection.
- Explicit approve, rework, and reject states.
- Golden regression fixtures for prompt and schema changes.

## Non-goals

- Automatic promotion or merging.
- Autonomous Skill creation.
- Mandatory cloud models.
- A vector database in the first release.

## Acceptance

- A real text PDF creates a Source draft and Card candidates.
- Every Card links to the final Source ID and includes evidence.
- Duplicate warnings identify overlap without changing existing Cards.
- Source approval is required before Card approval.
- Model failure preserves a useful text-only Source draft.
- Index, audit, golden tests, and the full unit suite pass.
