# AI 协作治理知识域章程

## Domain Boundary

AI 协作治理知识域是 Prajnavex 内的一个知识域，服务于人类与多个 Agent 共同完成研究、编码、写作、分析和工具操作。

它记录和组织：

- 宪法原则与不可逾越的边界；
- 规则、权限和审批条件；
- 任务、审查、发布和收尾流程；
- 人类、Codex、Claude 及其他 Agent 的角色；
- 工作中的知识、经验、失败教训和可复用方法；
- 审计、复查、升级和废弃机制。

## Authority Boundary

本知识域不是工作区 governance 本身，也不替代工作区或项目中的
`AGENTS.md`、`CODING_RULES.md`、`PROPOSAL_RULES.md` 等权威文件。

工作区 governance 决定什么规则真正生效；Prajnavex 负责把这些规则和经验结构化、可检索、可引用、可供 Agent 消费。

## First Subdomain

当前最完整的子域是 Codex 治理框架。它应被视为 AI 协作治理知识域的第一个实例，而不是整个领域的名称。

## Knowledge Classes

```text
规范性知识：应该遵守什么
描述性知识：系统和角色现在是什么样
经验性知识：过去发生了什么、学到了什么
```

经验和建议在获得明确批准前，不自动升级为规范性规则。
