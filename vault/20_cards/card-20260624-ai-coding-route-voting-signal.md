# 读 AI Coding 趋势要看大厂路线投票

## Core Idea

当一个产品形态还早期、事实噪声很大时，可以把大厂行为看成路线投票：它们不一定公开承认方向，但产品复刻、硬件绑定、入口优先级和工程投入能暴露它们对下一代宿主层的判断。

## Signals To Track

- 产品复刻：是否快速补齐同类 feature，说明该形态已进入战略关注。
- 企业版或硬件层投入：是否试图把 agent 与企业环境、设备或本地算力绑定。
- 固守上层入口：是否仍把 agent 放在网页、编辑器或聊天窗口里。
- 收购、投资或传闻：是否围绕更深宿主层补能力。
- 开发者生态反应：插件、SDK、开源项目和集成是否围绕同一入口聚集。

## Reading Rule

不要只读发布会文案，要看预算、工程路线和入口优先级。一个公司把资源放在哪里，通常比它说自己相信什么更有信息量。

## Caution

路线投票只能作为早期信号，不能替代事实验证。需要继续核查真实产品能力、用户留存、收入质量、开发者采用和安全边界。
