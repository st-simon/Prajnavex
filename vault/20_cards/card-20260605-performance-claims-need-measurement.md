# 交易表现故事必须回到度量口径

## Core Idea

交易书中的高收益故事适合激发问题，但不能直接当成可复制证据。Prajnavex 的投资素材应把表现叙事转化为可审查的度量问题。

## When Useful

- 看到“几年几百倍”“年化数百百分比”等表现叙事时。
- 比较交易者、基金经理或策略回测结果时。
- 把访谈类材料转化为研究卡片时。

## How To Apply

建立表现审查清单：

- 统计期从哪一天到哪一天？
- 最大回撤和最长修复期是多少？
- 资金规模变化后收益是否下降？
- 是否包含全部账户、全部交易和失败阶段？
- 收益来自少数极端交易，还是可重复的小优势？
- 是否有外部验证、税费滑点和融资成本说明？
