# AI 协作治理通过审计和复查持续升级

## Review Questions

- 规则是否仍然适用？
- 是否有权威来源和验证证据？
- 是否被 Agent 或用户频繁触发？
- 是否经常被违反或绕过？
- 是否与其他规则冲突？
- 是否应该升级为 Skill、降级为经验，或归档？

## Upgrade Loop

```text
使用 → 观察 → 复查 → 修订 / 升级 / 降级 / 归档 → 再验证
```

## Invariant

治理升级必须有明确理由、影响范围、验证方式和回退路径。
