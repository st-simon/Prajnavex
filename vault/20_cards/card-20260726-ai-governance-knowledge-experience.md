# AI 协作治理区分规则、知识和经验教训

## Three Classes

```text
规范性：应该怎么做
描述性：现在是什么样
经验性：过去发生了什么、学到了什么
```

## Promotion Path

```text
原始讨论 / 事件 → 经验卡 → 可复用方法 → Skill 草案 → 审核后的规则或 Skill
```

每一步都要保留来源、适用范围、置信度、验证日期和反例。

## Invariant

Agent 可以提出总结和升级建议，但不能把一次对话或一次成功经验自动写成永久规则。
