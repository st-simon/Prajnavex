# Codex 将 Proposal gate 与能力路由分开判断

## Proposal Gate

根据后果、可逆性、范围、成本和风险判断：

- `non-proposal`：低风险、清晰、可逆；
- `proposal`：治理、架构、权限、外部系统、数据或高风险变化。

## Capability Routing

在批准边界内选择最小必要能力：一个主能力，加上必要的支持能力；不能因为选中了某个 Skill 就扩大任务范围或获得额外权限。

## Invariant

Proposal 决定“能不能做”；路由决定“怎么做”。
