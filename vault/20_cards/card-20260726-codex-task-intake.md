# Codex 任务先确认目标、归属、范围和交付物

## Intake Questions

- 用户要解决的实际问题是什么？
- 任务属于工作区、哪个项目或一次性工作？
- 目标仓库、目录、分支和交付物是什么？
- 是否已经理解到无需提问，或必须先问一个关键问题？
- 当前工作树中的用户变化是否需要保留？

## Minimum Visible Checkpoint

如果理解已经足够，应明确说明：`完全理解，暂无需提问`；如果不够，只问改变范围、权限或交付物的最小问题集。
