# 风险控制先于观点正确性

## Core Idea

市场会奖励正确观点，但也会惩罚过大仓位、错误时不退出、把亏损变成身份防卫。交易系统必须先回答“错了怎么办”，再回答“对了能赚多少”。

## When Useful

- 建立交易前检查清单。
- 复盘重大亏损。
- 区分投资研究结论和可执行交易计划。

## How To Apply

每笔交易在入场前至少回答：

- 最大可承受亏损是多少？
- 哪个价格、事实或时间条件证明原假设失效？
- 如果连续亏损三次，仓位是否自动下降？
- 这笔交易是否大到会影响睡眠、判断或下次执行？

## Failure Mode

只研究买入理由、不定义退出条件，会把交易从概率游戏变成叙事忠诚。越优秀的叙事，越需要硬性的风险边界。
